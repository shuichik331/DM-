# 「資料請求」時に送付される資料のリサーチと構成分析

## 0. 調査目的とスコープ

企業または一般消費者が、企業の商品・サービスに関して「資料請求」を行った際に届く資料には、業界・request主体（法人/個人）によらず、ある程度共通した「型」が存在する。本ドキュメントでは、

- **BtoB（企業が企業に対して行う資料請求＝営業資料・会社案内）**
- **BtoC（個人が企業に対して行う資料請求＝不動産・保険・スクール等の個人向けサービス）**

の両面から資料の中身をリサーチし、共通する構成要素・パターンを分析する。

---

## 1. BtoB（法人向け）資料請求の構成

法人が資料請求フォームや一括資料請求サイト（例：BOXIL、Kaipoke等）経由で取り寄せる「営業資料・サービス紹介資料・会社案内」には、以下の14セクション構成が定石とされる（出典：才流「営業資料の作成・改善に使える62のチェックリスト」）。

| # | セクション | 目的・役割 |
|---|---|---|
| 1 | 表紙（タイトル） | 資料の主旨・対象読者を一目で伝える |
| 2 | サービスサマリー | サービス概要と対象顧客を要約提示 |
| 3 | よくある課題 | 読み手の課題を言語化し当事者意識を喚起 |
| 4 | 商品・サービス紹介 | 課題に対する解決策としての提示 |
| 5 | 導入後の効果 | 数字・グラフによる定量的な成果訴求 |
| 6 | 選ばれる理由 | 競合との差別化ポイント、信頼性の根拠 |
| 7 | 事例紹介（個別） | 具体的な導入企業の課題〜解決〜効果 |
| 8 | 事例一覧 | 導入企業ロゴ・社数の一覧で実績を可視化 |
| 9 | 料金 | 料金表・プラン比較 |
| 10 | ご利用の流れ | 契約〜導入〜運用までのプロセス |
| 11 | よくある質問（FAQ） | 懸念・疑問の先回り解消 |
| 12 | 会社概要 | 商号・所在地・資本金・設立年等の企業情報 |
| 13 | メディア掲載歴・受賞歴 | 第三者評価による信頼性の補強 |
| 14 | CTA（問い合わせ導線） | 次のアクション（商談・トライアル申込等）への誘導 |

**会社案内パンフレット単体**の場合は、上記のうち以下がコア要素として独立構成されることが多い（出典：エー・エム・ティー、パンフレット専科等）。

- 代表挨拶／企業理念・ビジョン
- 会社概要（沿革・組織図・資本金・拠点）
- 事業内容・取扱商品／サービス概要
- 実績・導入事例
- スタッフ紹介・事業所紹介
- CSR・サステナビリティ（近年増加傾向）

### BtoB資料に共通する設計思想
- 「読み手は資料を読みたいと思っていない」前提に立ち、**簡潔・数字・不安解消**の3原則で構成される。
- 課題提起 → 解決策 → 証拠（実績・事例・数字） → 条件（料金・流れ） → 信頼性補強 → 行動喚起、という**購買心理に沿った直線的なストーリー構成**になっている。

## 2. BtoC（個人向け）資料請求の構成

個人が資料請求をする代表的な業界（不動産・保険・スクール／resource講座）では、法人向けと異なり「契約実務書類」が同梱される点が特徴的。

### 2-1. 不動産（住宅・マンション）
- 物件パンフレット（間取り図・完成予想パース・立地図）
- 価格表・resource資金計画シミュレーション
- 周辺環境資料（学区・商業施設・ハザードマップ等）
- 要望に応じた個別追加資料（他物件比較等）

### 2-2. 保険
- 商品パンフレット（保障内容・保険料表）
- 設計書（対面販売商品の場合、個別試算入り）
- 申込書一式＋返信用封筒（通販型商品の場合）
- 約款・重要事項説明書（契約実務書類）

### 2-3. スクール・資格講座
- コース案内・カリキュラム表
- 受講生の声／体験談（漫画形式等の訴求コンテンツ含む）
- 就職・求人情報、キャリアプラン資料
- 教育訓練給付金など公的支援制度の案内
- Q&A（研修内容・資格・職業に関する疑問解消）

### BtoC資料に共通する設計思想
- **意思決定を後押しする「安心材料」**（体験談、Q&A、支援制度案内）と、**契約に直結する実務書類**（申込書・約款・設計書）がセットで届く。
- 個人の不安（本当に自分に合うか、続けられるか、費用は妥当か）を解消する情報が重視される。

## 3. BtoB／BtoCを横断した共通構造分析

両者を比較すると、資料は情報の性質によって以下の**5レイヤー**に分解できる。

```
① 導入レイヤー   … 表紙／企業理念／代表挨拶  → 何者か・何を目指しているか
② 提案レイヤー   … 課題提起／商品サービス紹介 → なぜ必要か・何を解決するか
③ 証拠レイヤー   … 実績／事例／体験談／数字   → 信用できるか
④ 条件レイヤー   … 料金／プラン／申込フロー   → 具体的にいくら・どう進むか
⑤ 行動レイヤー   … FAQ／CTA／申込書・約款     → 不安解消と次のアクション
```

- **BtoB**は①〜⑤を1冊の「資料」に集約し、ロジカルな説得構成に寄せる（意思決定者が複数・稟議を要するため、資料単体で説得力を持たせる必要がある）。
- **BtoC**は①〜③を「パンフレット・カタログ」、④〜⑤を「申込書・約款等の実務書類」として**分冊**する傾向がある（個人の場合、資料請求はまだ検討初期段階であり、実務書類は契約直前で必要になるため）。

### 送付形態の違い
| 観点 | BtoB | BtoC |
|---|---|---|
| 主な入手経路 | フォーム送信 → PDFダウンロード／メール送付が主流 | 郵送（紙媒体）も依然多い |
| 情報の焦点 | ROI・業務効率化・コスト削減効果 | 生活・将来設計への影響、安心感 |
| 意思決定者 | 複数人（稟議・比較検討） | 個人・家族 |
| 同梱書類 | 事例集・料金表・FAQ中心 | 申込書・約款・設計書など契約書類を含む |

---

## 4. まとめ・示唆

1. **資料請求される資料は「単なる説明資料」ではなく、購買・申込に至るまでの意思決定プロセスを1冊（または1セット）に凝縮した営業ツール**である。
2. 業界を問わず「課題喚起 → 解決策提示 → 証拠（実績・事例） → 条件（料金） → 行動喚起（CTA・申込）」という**共通のストーリーライン**が存在する。
3. BtoBは論理的説得（数字・事例・比較）に、BtoCは心理的安心（体験談・Q&A・支援制度）に比重を置く傾向がある。
4. 資料設計を行う際は、上記5レイヤー（導入・提案・証拠・条件・行動）を意識して章立てすることで、業界を問わず抜け漏れのない構成が作成できる。
